UAF ID Cards System

UAF ID Cards System is a desktop application used internally by the staff of the University of Agriculture Faisalabad, Burewala Campus, to manage student records and to issue and print student ID cards.

Google Drive backups

The application can optionally back up its data to the signed-in staff member's own Google Drive. It uses the drive.file permission, so it can only see the backup files it created itself, never any other file in the account.

The application is not a public service and is intended only for authorised campus staff.
