Privacy Policy

UAF ID Cards System - last updated October 2026

UAF ID Cards System ("the application") is a desktop program used by staff of the University of Agriculture Faisalabad, Burewala Campus, to manage student ID cards. This policy explains how the application uses Google account access.

What the application accesses

  • Your Google account e-mail address, only to confirm which account you connected.
  • Google Drive, using the limited drive.file permission. With this permission the application can create, read and delete only the files and folders that it created itself (a folder named "UAF ID Card Backups" and the backup files inside it). It cannot see any other file in your Drive.

How the data is used

  • Backup files are uploaded to your own Google Drive solely so that the campus can restore its data if a computer is lost or damaged.
  • The application does not collect, sell, share or transfer Google user data to any third party, and no data is sent to any server operated by the developer.
  • Your Google password is never seen by the application. Sign-in happens on Google's own page.
  • The sign-in token is stored only on your own computer, encrypted with Windows data protection, and is never uploaded.

Limited use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your control

You can disconnect Google Drive at any time from the application (Settings, Backup, Disconnect), or revoke access at myaccount.google.com/permissions. You may delete the "UAF ID Card Backups" folder from your Drive whenever you wish.
